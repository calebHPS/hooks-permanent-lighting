# Hooks Permanent Lighting – static site

Static site for hookspermanentlighting.com (GitHub Pages, no build server). Branding (colors, fonts, layout) matches the Hooks Property Services site (`calebHPS/hooks-site`).

## Structure
- `/` Home · `/permanent-lighting/` · `/about-us/` · `/contact-us/`
- Quote requests go to **Jobber** through the embedded Work Request form (Contact Us and Permanent Lighting pages). Every "Get A Quote" button points at Contact Us.
- Pages are generated by `tools/build.py` so the header/footer stay identical. Edit settings (phone, HIC number, Jobber form) and copy there, run `python3 tools/build.py`, commit the output.

## Settings in `tools/build.py`
- `PHONE_DISPLAY` – leave blank to hide it site-wide. `HIC_NUMBER` – PA HIC registration shown in the footer. The "Email Us" link points to the quote request page.
- `JOBBER_ID`, `JOBBER_FORM` – the Jobber Work Request embed (Jobber > Settings > Work Request Settings).

## Deploy
Repo Settings → Pages → Deploy from branch `main` / root. `CNAME` is `www.hookspermanentlighting.com`. DNS (Zoho): `www` CNAME → `<github-user>.github.io`; apex A records 185.199.108.153 / .109.153 / .110.153 / .111.153. Tick "Enforce HTTPS" once the cert issues.
